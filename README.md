# D3300-ML Research & Cinema OS — Nikon D3300 / аналог Magic Lantern

**Статус: Полный хост-симулятор + генератор пленочных профилей Picture Control + Live View фото-ассистенты + глубокий реверс-инжиниринг прошивки Nikon C:1.02.**

Проект исследует и реализует функционал расширения возможностей камеры **Nikon D3300** (процессор EXPEED 4, ядро ARM Cortex-A9, RTOS T-Kernel 2.0) по аналогии с Magic Lantern для Canon:
- **Fujifilm Film Simulation**: генерация и прямой экспорт на SD-карту аутентичных бинарных профилей Picture Control (`.NOP` / `.NCP`) для получения знаменитых пленочных цветов Fuji прямо из процессора камеры.
- **Live View Photo Assist**: высокоскоростной пикинг фокуса (Focus Peaking), зебра пересветов (Exposure Zebra) и живая гистограмма (Live Histogram HUD).
- **Cinema OS Menu & UI**: графическое оверлей-меню с распознаванием длительного удержания кнопки MENU, современной пропорциональной типографикой (Modern Sans) и плавными анимациями.
- **Custom Clean Information Screen**: минималистичный кино-экран параметров съемки взамен перегруженного заводского дисплея Nikon.
- **Безопасная архитектура Payload**: исполнение только в оперативной памяти (DRAM `0x10480000..0x104A0000`) без записи в постоянную память (SPI Flash ROM).

## 1. Ключевые возможности

### 1.1. Пленочные профили Fujifilm (Picture Control Engine)
Модуль `modules/fuji_film_sim.c` генерирует 100% валидные 700-байтные бинарные файлы `.NOP` и `.NCP`, полностью соответствующие внутренней спецификации Nikon Picture Control (верифицировано утилитой `dumpncp.pl`):
- **CLASSIC CHROME**: приглушенная сатурация, теплый янтарный тон, матовый подъем точки черного (+2.2%), мягкий спад в светах.
- **FUJI VELVIA**: сочные пейзажные цвета, глубокий контраст, изумрудная зелень и насыщенное небо.
- **FUJI ACROS**: благородный ч/б профиль с высоким микроконтрастом и эмуляцией спектрального отклика желтого светофильтра (`Filter: YELLOW`).
- **CLASSIC NEGATIVE**: эстетика пленки Superia 400 с придавленными жесткими тенями и винтажным зеленым оттенком.
- **FUJI ASTIA / SOFT**: мягкая градация полутонов и светящийся скинтон для портретной съемки.

**Экспорт профилей на SD-карту:**
```bash
./build/d3300_sim --export-fuji-profiles /Volumes/NIKON_SD
```
Файлы сохраняются в `/NIKON/CUSTOMPC/PICCON01..05.NOP` и `.NCP` и импортируются в штатном меню камеры (*Меню съемки → Режим Picture Control → Управление Picture Control → Загрузить/сохранить → Копировать в камеру*).

### 1.2. Фото-ассистенты реального времени (Photo Assist Engine)
Модуль `modules/photo_assist.c` реализует обработку кадра в реальном времени на целочисленной арифметике (время исполнения < 0.5 мс):
- **Focus Peaking**: градиентный фильтр Собеля с выбором цвета (`GREEN`, `RED`, `CYAN`, `YELLOW`, `WHITE`) и 3 уровнями чувствительности (`LOW`, `MEDIUM`, `HIGH`).
- **Exposure Zebra**: динамическая диагональная штриховка областей с превышением допустимой яркости (`100%`, `95%`, `90%`, `75%`).
- **Live Luma / RGB Histogram**: полупрозрачный HUD-блок 132×60 пикселей в углу экрана с индикацией пересвета (красный маркер клиппинга).

### 1.3. OSD Меню Cinema OS & Типографика
- **Умное разделение кнопки MENU**:
  - Короткое нажатие (<500 мс) — сквозной пропуск в заводское меню Nikon.
  - Удержание (≥500 мс) — открытие меню D3300-ML с анимированным круговым индикатором удержания.
- **5 структурированных вкладок**: `SHOOT`, `EXPO`, `OVERLAY`, `MOVIE`, `SYSTEM`.
- **High-Resolution Typography**: четкий пропорциональный шрифт `Modern Sans` (14px заголовки, 10px подписи) с оптическим кернингом и селектором гарнитур в меню (`MODERN SANS`, `MONO TECH`, `RETRO MATRIX`).

### 1.4. Чтение аппаратного статуса из RAM
Модуль `core/dml_camera_status_hw.c` считывает текущие съемочные параметры напрямую из рабочих структур Nikon в оперативной памяти (`0x10491580`, RTTI `17CKRRCCameraStatus`):
- Выдержка (`tv_code`), диафрагма (`av_code`), чувствительность (`iso_code`).
- Уровень батареи (включая флаг критического разряда), поднятие и режим вспышки, активная точка автофокуса из 11 доступных.

## 2. Быстрый старт и запуск симулятора

### Требования
- Любая POSIX-система (macOS, Linux, WSL).
- Компилятор C11 (`clang` или `gcc`), `make`, `python3`.

### Сборка и запуск тестов
```bash
make clean && make test
```
Запускает все 11 C-тестовых наборов и 37 Python-тестов. Все бинарники компилируются с флагами `-std=c11 -Wall -Wextra -Werror -O2`.

### Интерактивный запуск симулятора
```bash
./build/d3300_sim --interactive
```
Управление с клавиатуры:
- `m` — короткое нажатие MENU (заводское меню Nikon).
- `H` — удержание MENU (открытие D3300-ML Cinema OS).
- `w` / `s` — навигация вверх/вниз по пунктам меню.
- `a` / `d` — переключение вкладок меню.
- `e` — изменение/переключение параметра (`[OK]`).
- `i` — переключение кастомного экрана информации (Custom Info Screen).
- `[` / `]` — изменение выдержки в виртуальной RAM Nikon.
- `-` / `=` — изменение диафрагмы.
- `,` / `.` — изменение ISO.
- `b` — цикл уровня батареи (100% → 84% → 50% → 20% → 5% critical).
- `f` — поднятие/опускание вспышки.
- `p` — сохранение скриншота экрана в `screenshot.bmp`.
- `q` — выход.

### Экспорт скриншотов через CLI
```bash
# Снимок Live View с активным Focus Peaking, Зеброй и Гистограммой:
./build/d3300_sim --screenshot-assist assist_preview.bmp

# Снимок OSD меню (вкладка OVERLAY):
./build/d3300_sim --screenshot-tab 2 overlay_tab.bmp

# Снимок меню с активным профилем Classic Chrome:
./build/d3300_sim --screenshot-fuji 1 fuji_preview.bmp

# Снимок кастомного экрана съемочной информации (Info Screen):
./build/d3300_sim --screenshot-info info_screen.bmp
```

## 3. Архитектура репозитория

```
├── core/
│   ├── dml_camera_status.h/.c     # Модель съемочных параметров камеры
│   ├── dml_camera_status_hw.h/.c  # Парсер аппаратных структур RAM (17CKRRCCameraStatus)
│   ├── dml_draw_buffer.h/.c       # Графический движок DrawBuffer (RAM 0x104A0868)
│   ├── dml_fonts_data.h/.c        # Растровые таблицы шрифтов (Modern Sans, Mono, Matrix)
│   ├── dml_info_screen.h/.c       # Рендерер минималистичного экрана информации (Info Screen)
│   ├── dml_menu.h/.c              # Ядро меню, диспетчеризация команд и логика удержания
│   ├── dml_menu_screen.h/.c       # Отрисовка вкладок, строк, бейджей и анимаций меню
│   ├── dml_nikon_adapter.h/.c     # Адаптер кодов кнопок RelayEventEx / COPNO
│   └── dml_tkernel.h/.c           # Прослойка T-Kernel 2.0 RTOS и подавление задач (quieting)
├── modules/
│   ├── fuji_film_sim.h/.c         # Движок пленочных профилей Fujifilm (Picture Control 700B)
│   ├── photo_assist.h/.c          # Focus Peaking, Exposure Zebra, Live Histogram
│   └── intervalometer.h/.c        # Автоматический интервалометр для таймлапсов
├── payload/
│   └── dml_payload.h/.c           # Автономный загрузочный модуль DRAM (0x10480000..0x104A0000)
├── sim/
│   └── main.c                     # Хост-симулятор камеры с полным виртуальным железом
├── tests/                         # 11 C-бинарников тестирования и 37 Python-тестов
├── tools/                         # Утилиты декодирования прошивки, дизассемблирования и поиска
└── reports/                       # Детальные отчеты реверс-инжиниринга прошивки C:1.02
```

## 4. Результаты реверс-инжиниринга прошивки C:1.02

1. **RTOS**: Камера работает под управлением **T-Kernel 2.0** (спецификация TRON). Точка входа ядра `0x9002E740`.
2. **Контроллер кнопок**: Подтверждена цепочка `COPNOQueueButton` → Mailbox `MBF_OPNO` (`0x1012B908`) → `CSYSCAppButtonController`.
3. **Графическая подсистема**: Таблица дескрипторов `DrawBuffer` из 20 записей размещена в RAM по адресу `0x104A0868`.
4. **Безопасность**: Запись в постоянную память (SPI ROM) исключена. Модуль D3300-ML размещается исключительно в DRAM и очищается при выключении питания.
